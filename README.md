# ThermEcoWat-Geothermal-Resources-Dashboard
[Geothermal resources Power BI](https://app.powerbi.com/view?r=eyJrIjoiZWUwOTQ4OTYtZjJlNy00NzVmLTg2YzUtNTU1ZjNhYWQ4YTdlIiwidCI6ImRjYmI5NDU3LTQxNzItNDNmOS1iN2FkLTQ0MzAwZjRkZWEyNiIsImMiOjl9)

Interactive Power BI dashboard developed to support the visualization and analysis of environmental, hydrogeological and climatic data within the ThermEcoWat European Project.
The dashboard contributes to the characterization of thermal water resources and supports the assessment of climate change impacts on hydrothermal systems.
## Objectives

- Integrate environmental and hydrogeological datasets.
- Explore temporal and spatial trends.
- Support interpretation of thermal water systems.
- Facilitate communication of project results.
- Provide decision-support information for resource management.

## Technologies

- Power BI
- Power Query
- DAX
- Excel
- GIS datasets
